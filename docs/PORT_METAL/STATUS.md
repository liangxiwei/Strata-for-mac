# The Metal port - status

One row per module; the Status column is one of `not started` / `in progress` / `parity green` / `done`.
"parality green" cites the test that passed and on what machine. **This file is the truth: update it the
moment a module's state changes, in the same commit as the code.**

Machine of record so far: Apple M2 Max (12 cores, 96 GB RAM), macOS 26.5, Xcode 17 clang, CMake 3.30.
